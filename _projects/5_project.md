## Overview

Every Saturday: dedicated offensive security study time. Notes, tool references, technique breakdowns, and lab documentation all committed here as a living knowledge base.

## Format

Each session covers one or more of:
- Tool deep-dive (flags, use cases, gotchas)
- Attack technique with lab reproduction
- HTB/THM machine methodology notes
- OSCP-path topic (Active Directory, port forwarding, AV evasion basics)

## Topics Index

- Reconnaissance: Nmap, Masscan, Amass, Subfinder
- Web: Burp Suite, ffuf, SQLmap, XSS methodology
- Password attacks: Hashcat wordlists, rule-based cracking, Hydra
- Post-exploitation: LinPEAS, WinPEAS, BloodHound, Mimikatz
- Pivoting: Chisel, Ligolo-ng, SSH tunnelling

## Why Public

Forcing accountability. If it's on GitHub, it exists. If it's in a local folder, it doesn't.
