## Overview

Weekly CTF practice across HackTheBox and TryHackMe. Every rooted machine gets a writeup committed to this repo — methodology, tools used, key findings, and lessons learned.

## Discipline

- **Root → Writeup → Commit** — no exceptions
- Document what worked AND what didn't
- Note every new technique encountered

## What's Inside

- Machine writeups (enumeration → foothold → privesc → root)
- Custom Python and Bash automation scripts
- Notes on tools: Gobuster, ffuf, Hydra, pwncat, Ligolo-ng
- Privilege escalation checklists

## Skills Being Built

`Enumeration` · `Web exploitation` · `Password attacks` · `Privesc (Linux/Windows)` · `Pivoting` · `Active Directory basics`
